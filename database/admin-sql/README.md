# Admin SQL scripts for StreamLoft

Open each `.sql` file in pgAdmin and run the example queries directly.

| Script | Purpose |
|---|---|
| `create_user.sql` | Create a new user |
| `update_user.sql` | Update a user's display name |
| `create_destination.sql` | Create a global platform destination (run once per platform) |
| `assign_destination.sql` | Assign a destination to a user |
| `update_destination.sql` | Edit platform destination name or RTMP URL |
| `edit_streamloft_stream_key.sql` | Regenerate user's StreamLoft stream key |
| `edit_destination_stream_key.sql` | Set user's stream key for a destination |
| `list_users.sql` | List all users |
| `list_user_destinations.sql` | List destinations for a user |
| `list_broadcast_sessions.sql` | List broadcast sessions |
